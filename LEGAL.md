# Legal & Licensing

## About OpenDis2

OpenDis2 is a frozen technical proof-of-concept snapshot of an independent source port / engine reimplementation project for Disciples II: Rise of the Elves. The repository contains source code, build tooling, binary format documentation, authored runtime configuration, and synthetic fixtures.

The repository does **not** include proprietary game assets, wholesale extracted databases, or redistributable game content.

## What This Repository Contains

- C++ source code and headers
- Build configuration files (CMake, vcpkg)
- Documentation of binary formats (summarized reverse-engineering findings)
- Authored runtime configuration files (render profiles, layout offsets)
- The authored repository fixture `testdata/test_map.sg`
- Asset key mappings, symbolic names, and numeric identifiers needed by the runtime to load assets from a user-provided local game installation
- Synthetic test fixtures
- Development tooling scripts
- Compatibility identifiers, ids, archive names, animation names, asset keys, and manually authored mapping tables needed for runtime interoperability with original game data

## What This Repository Does NOT Include

This repository does **not** include original proprietary game assets or extracted media, including but not limited to:

- Graphics, sprites, textures, or images from the original game
- Sound effects, music, or voice files
- Video files (SMK, BIK, or other formats)
- Font files from the original game (`.mft` or otherwise)
- Maps, campaigns, or playable scenarios, except for the single authored fixture `testdata/test_map.sg`
- Archived game databases, complete data tables, or scripts from the original game
- Game archives (`.ff`, `.mqdb`, `.wdb`, `.wdt`, `.sg`, `.sav`, `.mpq` files)
- Wholesale extracted dumps, generated frame catalogs, or full unit/attack tables
- Any files that constitute a direct copy or derived redistribution of the original game's proprietary content

Original game scenarios and third-party scenarios must not be committed. The `testdata/test_map.sg` fixture is the single permitted authored repository scenario and contains scenario structure only; it still requires the user's legally obtained local installation of Disciples II: Rise of the Elves. This exception does not permit original game assets, extracted archives, generated frame catalogs, or other proprietary content.

## User Responsibility

The tools in this repository require the user to provide their own **legally owned local copy** of Disciples II: Rise of the Elves (or another supported version). The tools process files from the user's local game installation and do not distribute or bundle any portion of the original game.

Any assets extracted or data generated by these tools from the original game are for the user's **local personal use only**. Extracted assets may be used with the OpenDis2 engine locally but must not be redistributed through this repository or any other public channel.
