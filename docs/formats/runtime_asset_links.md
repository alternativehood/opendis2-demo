# Runtime Asset Links Format Boundary

The reference-resolver stage defines a package-level JSON relationship graph.
It establishes no new Section 13 conclusions about MQDB, OPT, DBF, DAT, DLG,
WDB, or WDT binary layout.

Unit animation matching and symbolic sound handling are runtime resolver
policies, not binary-format discoveries.

Battle visual viewer script integration is also runtime-only. It wires JSON
playback into `opendis2 battle-viewer` and resolves no additional Section 13 binary
format unknowns.

AOE battle visual script events are runtime JSON semantics only. They add no
new binary format conclusions.

Battle visual effect placement is runtime lowering only. It adds no new
Section 13 binary format conclusions.

Battle visual cue fan-out hardening is runtime step execution only. It adds no
new Section 13 binary format conclusions.
